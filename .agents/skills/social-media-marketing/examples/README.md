# Example social creatives

Reference implementations of Monomastic social media posts. Consult these for
conventions (canvas setup, tokens, signature motifs, RTL handling, screenshot
readiness) before making your own — then make your own, don't copy.

| File | Format | Notes |
|---|---|---|
| `announcement-en.html` | Instagram Post 1080×1080 (English) | "A website, written by hand." announcement, on-brand. |
| `announcement-ar.html` | Instagram Post 1080×1080 (Arabic, RTL) | Arabic localized version of the same idea. |

These are **examples, not the deliverable** for any request — always create fresh
content for the specific request you are given.
