# Visual Design (after message is locked)

Translate the marketing concept into a professional social creative. Think like a
senior graphic / social media designer, not a web developer. Design the composition
to be understood in 1–3 seconds, and to feel unmistakably like Monomastic.

Read `product-and-brand.md`'s visual-identity reference before designing — you must
design on-brand.

---

## Design principles for this brand

- **On-brand, more expressive, not generic-web.** The post may be bolder than the
  landing page, but it must read as the same brand: warm paper, warm ink, muted red /
  blue / yellow, handwritten display accents, tape / sticky-note / ruled-notebook
  motifs, small radius, hard offset shadow.
- **Spend boldness in one place.** Let one signature element carry the idea (e.g. a
  large handwritten word, a taped sticky note, a red-underlined headline). Keep the
  rest quiet and disciplined. Cut decoration that doesn't serve the message.
- **Hierarchy is everything.** Order of attention: (1) Hook → (2) focal point →
  (3) core message → (4) supporting info → (5) brand/product recognition → (6) CTA.
- **Whitespace is a feature.** Don't fill the canvas. Use the paper background and
  breathing room.
- **Design supports the message.** A visually impressive post that communicates
  nothing is a failure; so is correct copy in a boring generic template.

---

## Reference palette (from production tokens)

Warm off-white paper `#f5efdf` · surface `#ebe3d0` · ink `#2a2622` (primary text) ·
ink-2 `#5c544a` · ink-3 `#8e8576` · red accent `#b23a48` · blue accent `#2d5ba8` ·
yellow tape `#e8b53c` · green `#4a6b3d` · line `#b4c8e8`.

- Never pure black `#000` or pure white `#fff` anywhere.
- Hard offset shadow `4px 4px 0` in translucent ink.
- Radius ~4px. Tape at a slight `rotate(-2deg)`.

---

## Typography choices for the post

- **English:** a handwritten display face (Caveat) for accent words / the hook /
  sticky notes, used with restraint; a warm serif body for the readable message; a
  mono face for small labels/captions/step numbers (uppercase, letterspaced).
- **Arabic:** Arabic **serif** for headings/display (never the English handwritten
  face), Arabic sans/serif for body. `dir="rtl"` and correct right-aligned flow.
- Keep a clear type scale with enough contrast between the headline, a body line, and
  a tiny caption. Tiny text must still be readable at the intended screenshot size.

---

## Composition guidance

- Choose the focal point deliberately: a giant handwritten word, an oversized number,
  a sticky note pinned to the hook, a red-underlined phrase.
- Support with a short upright serif line or a two-item bullet set (very short).
- Include small brand signals: the `★` mark, a tape tag with "Monomastic", a
  "— signed, monomastic" footer line, or the `yourname.monomastic.site` hint — enough
  for brand recognition without clutter.
- Add CTA as a clear button/pill with the hard-offset shadow and red accent, with the
  arrow flipping in RTL.

---

## Bilingual layout

Decide (and state) the delivery shape:

- **Single bilingual canvas** showing English and Arabic together (e.g. split layout
  LTR/English + RTL/Arabic, or the two aligned as "one brand, one voice"), or
- **Two separate monolingual creatives** (English post + Arabic post), or
- **One post, one language** if the user asked for a single language.

Whatever you choose, both versions must be designed, not one translated. RTL layout
mirrors direction and flips arrows. Both deliverables share the same palette, motifs,
and voice.

---

## Output of this stage

A short design direction you will implement: focal point, layout sketch (ASCII), the
palette uses, the type roles, the signature element, and which bilingual shape you'll
build. Derive every color and type decision from `product-and-brand.md` — do not
introduce off-brand values.
