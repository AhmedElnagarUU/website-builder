Note on diversity

Set A · 7 dark/neon reskins (variants 1–7): same dark/neon spec, different accent colors. A "reskin once" exercise.

Set B · 7 redesigned-from-scratch (variants 8–14): completely different design languages — each from a real-world tradition (Japanese stationery, Swiss typography, Memphis, Apothecary, Broadsheet, Outrun, Field notebook).

Pair with the existing design-scratch/landing-variants/ for more comparison.
